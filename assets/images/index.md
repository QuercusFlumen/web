# IMAGES  
## Archivo visual de Quercus Flumen

Esta carpeta organiza el material visual utilizado dentro del proyecto Quercus Flumen.

<br>

El objetivo es mantener:
- estructura
- coherencia visual
- organización interna
- y facilidad de mantenimiento a largo plazo.

<br>

Las imágenes forman parte importante de:
- identidad
- documentación
- observación
- producto
- y comunicación visual del proyecto.
