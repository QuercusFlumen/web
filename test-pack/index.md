# TEST PACK  
## Gracias por formar parte de WILD


Lo que tienes entre las manos no es simplemente una muestra.

Es una pequeña parte del proceso de desarrollo y observación que existe detrás de Wild.

---

# ¿QUÉ ES TEST PACK?

Wild lleva mucho tiempo evolucionando desde:
- observación ecológica
- transformación vegetal
- comportamiento del agua
- y experiencia acumulada dentro de sistemas reales.

<br>

Actualmente creemos que Wild ya ha alcanzado un formato comercial:
- coherente
- equilibrado
- y muy sólido como herramienta blackwater.

<br>

Pero seguimos pensando que la experiencia real del usuario sigue siendo fundamental.

<br>

Cada:
- acuario
- agua
- microbiología
- fauna
- y forma de trabajar el sistema

puede desarrollar comportamientos distintos.

<br>

Precisamente por ese motivo nace TEST PACK.

---

# OBSERVAR ANTES QUE AFIRMAR

TEST PACK no busca únicamente “probar un producto”.

<br>

Busca seguir observando:
- extracción
- comportamiento del agua
- estabilidad
- evolución del sistema
- y percepción real dentro de acuarios vivos.

<br>

Algunas diferencias entre lotes pueden ser:
- mezcla de fases
- granulometría
- cribado
- o pequeños ajustes desarrollados alrededor del perfil principal de Wild.

<br>

No buscamos respuestas correctas.

Buscamos observación honesta.
